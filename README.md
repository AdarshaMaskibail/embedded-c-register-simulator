# embedded-c-register-simulator
Embedded C project demonstrating register-level programming, bit manipulation, control/status registers, and modular C programming.

## Concepts
A small Embedded C project that simulates memory-mapped control/status registers.
- Bit manipulation and masking
- `uint8_t`/`uint32_t`
- Register abstraction
- Modular C programming
- GCC + Make

## Build and run
```bash
make
./register_simulator
```
## Example operations
The program sets and clears control bits and decodes the simulated status register.

## Skills demonstrated
Embedded C, bitwise operations, register-level concepts, modular programming, Make.
